The basics

What Twenty integration actually means

It means Twenty and the other tools your team uses swap data automatically, so people, companies, opportunities, notes and tasks stay consistent without retyping. A new Stripe customer becomes a Twenty record, and a closed-won opportunity posts to Slack, in seconds rather than at the next team meeting.

Twenty is a modern, community-driven alternative to Salesforce and HubSpot, built on a metadata-driven data model. It ships with standard objects and lets you add custom objects, fields and relations from the interface. Each new object instantly gets matching REST and GraphQL endpoints that use your own names, so there are no opaque IDs to decode.

Choosing a route

Six ways to connect Twenty, and when each one fits

Twenty generates a REST and a GraphQL API from your workspace, secured with an API key or OAuth. A Metadata API handles schema, webhooks announce record changes, and native sync, workflows and iPaaS templates sit on top for teams that don't want to maintain code.

REST APIAuto-generated CRUD

Best when you need simple create, update and list flows.

Trade-off endpoints are per-workspace, so everything is mapped to your schema.

GraphQL APIRelations, filters, batch upserts

Best when a sync is nested or two-way across related objects.

Trade-off a steeper learning curve, worth it for relation-heavy flows.

Metadata APISchema management

Best when an integration needs custom objects created for it.

Trade-off schema changes should be reviewed and version-controlled before go-live.

WebhooksPush on create, update, delete

Best when a downstream flow should fire the instant a record changes.

Trade-off you still fetch the full record over the API after the ping.

Native sync and workflowsBuilt-in email and calendar

Best when you want standard activity logging and simple no-code automation.

Trade-off it won't cover custom multi-system mapping.

iPaaS or custom middlewareZapier, Make, n8n or code

Best when you need fast standard flows, or unusual rules and AI automation.

Trade-off iPaaS is a subscription forever, and custom needs a partner to maintain it.

Twenty's native sync, its workflow builder or an iPaaS template is often the right answer. We'll say so, help you set it up, and only build custom when your object model demands it.
